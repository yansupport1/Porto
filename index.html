Sering ditanya

Berapa lama pengerjaannya?

Landing page 3–5 hari, website profil 1–2 minggu, aplikasi APK 3–6 minggu tergantung jumlah fitur.

Sistem pembayarannya bagaimana?

DP 50% saat mulai, sisanya setelah project selesai dan kamu setujui hasilnya. Transfer bank atau e-wallet.

Source code diserahkan penuh?

Ya. Semua file, database, dan akses server diserahkan lengkap beserta panduan singkat cara mengelolanya.

Kalau setelah rilis ada bug?

Ada garansi bugfix 30 hari tanpa biaya tambahan. Setelah itu tersedia paket maintenance bulanan.

Bisa lanjutkan project yang sudah jalan?

Bisa. Kirim source code-nya, saya audit dulu, lalu kasih rekomendasi perbaikan dan estimasi biaya.
